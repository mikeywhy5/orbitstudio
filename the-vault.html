How to use it. Every stage below runs the real code, live. Hit ↻ on a stage to replay a one-shot animation. While you are walking a client through it, tap the ★ on anything they like → filter to Favorites to review just those → Export copies the lot as a plain text list you can paste into a quote. Favorites persist if you close the page.
What you copy. A self-contained fragment: a <style> block, the markup, and a <script> block where needed. Paste it straight into any HTML page. No libraries, no build step, nothing to install.
Two things to adjust. Stages use the Orbit dark surface, so colors are tuned for dark backgrounds — retune them for lighter sections. Class names are prefixed per effect so nothing collides when you paste several onto one page.
Fonts. The chrome and the snippets call for Space Grotesk and Inter, matching the Orbit Studio site. Both load from Google Fonts, so this page needs a connection to look exactly on-brand; offline it falls back to Bahnschrift and Segoe UI and stays perfectly usable. Pasted snippets inherit whatever your page already loads.
The curve glyph on each spec line is that effect's actual easing function, drawn to scale. A curve that overshoots the top box is an overshoot easing; a straight diagonal is linear, which almost always means an infinite loop.
